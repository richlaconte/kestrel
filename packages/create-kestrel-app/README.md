# create-kestrel-app

Scaffold a [Kestrel](https://github.com/richlaconte/kestrel) app — just React,
actually native:

```sh
npx create-kestrel-app my-app
```

Templates: `react` (default — React 18 + Vite + TypeScript, HMR into the native
window) and `vanilla` (`--template=vanilla`). See the `kestreljs` package and the
[repo](https://github.com/richlaconte/kestrel) for the pre-alpha status notes. MIT.
